## 5. Known Limitations
1. **Memory constraints**: Scaled down to 1,500 transactions per experiment to avoid OOM on CPU.
2. **Formal DP accounting**: Epsilon = `not_computed`. Clipping + noise applied but no RDP accountant integrated.
3. **Severe Non-IID collapse**: PR-AUC = 0.00 under severe partitioning (genuine result, not a bug).
4. **FedProx**: Did NOT outperform FedAvg in our experiments. Documented honestly.
5. **Explainability**: Only TP and FP cases found (model predicted FN/TN but with less distinctive scores). Approximation documented.
6. **Old baseline JSONs**: `results/metrics/fedavg.json` etc. contain all-zero values from an earlier run that OOMed. The non-IID multi-seed experiment provides the authoritative baseline numbers.

## 6. Skipped/Failed Experiments
- **Trimmed Mean / Krum aggregation**: Not implemented (would require major architectural changes per Phase 12 guidelines).
- **Formal DP epsilon**: Not computed (documented limitation).
- **Customer and Merchant node types**: Not added to graph schema (would require schema changes; documented as future work).
